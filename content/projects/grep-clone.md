Rust reimplementation of GNU grep with regex, parallel search, and syntax highlighting.

## Overview

- Reimplemented GNU grep from scratch with regex, parallel search, and syntax highlighting
- Implemented parallel search using Rayon to scale across multi-core systems
- Benchmarked within 5% runtime and 4.5% memory usage of GNU grep
